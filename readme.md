# Capitalismo e Esquizofrenia

Repositório onde exploro algumas ideias, algumas confusões e alguns estudos que venho realizado durante o processo de enlouquecimento que sofremos com a situação cotidiana.

Não existe nenhuma presunção em ser sério, ou mesmo ser correto e coeso nos escritos dentro deste repositório, porém certos momentos mais sérios serão vistos aqui, bem como momentos menos sérios. Alguns estudos também serão explorados, de conteúdos variados.
